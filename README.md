# Security Labs Portfolio

Hands-on labs completed independently, outside of coursework, to build practical skills in offensive and defensive security. All labs were performed in isolated virtual lab environments (VirtualBox/VMware VMs) that I built and owned — no production systems, third-party networks, or real user data were involved.

## Background
AAS Cybersecurity student at Gwinnett Technical College (IS23), working toward CompTIA Security+ and CySA+.
